PNG と .sprite-spec.json をドロップしてスプライトシートを確認・調整

生成コマンド: pyxel-rust sprite_prompt "description" --name mychar

📖 ワークフロー（使い方を確認）

① 準備・ファイル読み込み

  1. AIツール（sprite_prompt）でスプライトシートPNG＋.sprite-spec.jsonを生成
  2. 両ファイルをドロップゾーンにまとめてドロップ
  3. 検証情報（幅・高さ・フレーム数）を確認

② フレームキャプチャ（1枚目タブ）

  1. シート上でマウスを動かしてフレーム枠をプレビュー確認
  2. 余白距離（↑↓←→）でフレーム内の位置をチェック
  3. クリック or Enter でキャプチャ（複数可）
  4. キーボード矢印キーで枠を移動（Shiftで1px精密移動）
  5. 「📥 PNG エクスポート」で合成シートを出力（背景はオレンジ #FF8000）

③ 背景除去（2枚目タブ）

  1. 「🎨 クロマキー除去」でスポイト→背景色を選択
  2. 許容幅スライダーで除去範囲を調整（0〜255）
  3. 取れない塊は「🧹 消しゴム」でドラッグ消去
  4. 「✨ アルファ精密化」で半透明境界を滑らかに
  5. 「📐 正規化エクスポート」で最終PNG出力

④ ヒント

  • F0（最初のフレーム）の座標が基準として常時表示される
  • アニメ行は「＋ 行追加 / － 行削除」で管理
  • クロマキーは後工程なので、キャプチャ段階では除去不要
  • プレビューの市松模様 = 透明部分

PYXEL CUBE / OFFICIAL EXAMPLES

公式の6デモを、Rustで。

同じモデルとシーンを使ったRust移植版です。Rust版と公式版を並べて、描画や操作、衝突・物理の動きを見比べられます。

3Dを指定した解像度で描画します。解像度を変更するとRust版だけを最初から開始します。公式版は元の解像度のままです。

デモを読み込み中…

左右の画面はそれぞれクリック／タップして操作できます。公式版は開始画面をクリックしてください。再生時刻と入力は同期しません。狭い画面では縦に並びます。

公式版を別タブで開く ↗公式Pythonソース ↗Rustソース ↗

Rust版は公式Pyxel 3.0.0を基準に移植しています。描画・操作・モーション・衝突／物理に加え、効果音は同じMMLを公式シンセサイザーでWAV化して再生します。公式公開ページは更新される場合があります。切り替えると、そのバージョンを最初から開始します。

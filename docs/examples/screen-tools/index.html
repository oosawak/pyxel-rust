画面・録画・Nodeの確認

左は画像、右はタイルマップの透視投影です。画面・フォント・カーソルの共有画像を直接編集し、ブラウザ内で録画GIFを保存できます。

読み込み中…

通常は自動で描画します。手動フレームの確認モードでは「画面を描く」「直接編集」「1フレーム進める」の順で表示できます。「表示を続ける」は描いた画面を保持して表示を続けます。実行中の自動ループと手動フレームの併用はできません。

ブラウザの表示切替はCanvas用の簡易処理です。公式のxBR・CRTシェーダーと同一の画質ではありません。

Nodeシーンは共有Meshの階層と材質を使い、更新・描画・衝突・破棄の各通知回数を下に表示します。Motionの自動再生はNodeアニメーションの確認ページで試せます。

録画は開始後の論理画面を保存します。Canvasの日本語テキスト重ね描画・カーソル・簡易表示効果は含みません。保存後は録画内容をクリアし、録画を継続します。画面サイズ変更時は録画を終了します。録画バッファの上限は32MiBです。

ブラウザのユーザーデータはアプリごとのlocalStorageに保存します。同じサイト・ブラウザに保持され、デスクトップのフォルダーとは異なります。

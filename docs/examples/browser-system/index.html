ブラウザ・ファイルAPIの確認

画面サイズ・全画面・タイトル・アイコン、256色、文字入力とファイルの読み書きを試せます。ファイルはこのブラウザ内で処理します。

読み込み中…

全画面表示はブラウザの許可が必要です。

入力を開始すると、日本語IMEでの入力も受け付けます。確定した文字を下の状態欄に表示します。通常の英数字は画面をクリックしても入力できます。

pyxresは公式の画像・タイルマップ・従来の音声配列・曲配列を保存します。MML・PCM・Tone・Font・Nodeは含みません。パレットは別ファイルです。TMXは公式コアと同じく、埋め込みタイルセット・8×8タイル・CSV層に対応します。

画面へファイルをドロップすると、名前・バイト数・先頭部分を状態欄に表示します。

ファイル操作を試せます。

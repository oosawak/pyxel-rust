🎮 Pyxel-Rust

Rust WebAssembly wasm-bindgen Canvas 2D

Pyxel ライクな API を持つ Rust 製ゲームライブラリ。 ブラウザ上で動作する WebAssembly ゲームを Rust で開発できます。

🔧 デュアルバックエンド構成
本プロジェクトは Pyxel の API 仕様をベースに Rust で実装したゲームライブラリです。 デスクトップビルドでは pyxel-core（SDL2）または wgpu バックエンド を使用し、 WebAssembly ビルドでは wasm-bindgen + Canvas 2D API（web-sys）による独自バックエンドで動作します（Emscripten 不使用）。 用途に応じてバックエンドを切り替えられる柔軟な構成になっています。
GitHub リポジトリを見る (oosawak/pyxel-rust)

🏗️ アーキテクチャ

  • 描画バックエンド（デスクトップ）: pyxel-core（SDL2）— Pyxel の C コアを利用、または wgpu バックエンド
  • 描画バックエンド（ブラウザ）: Canvas 2D API（web-sys）— wasm-bindgen 経由（Emscripten 不使用）
  • ウィンドウ管理: winit（デスクトップ）/ ブラウザ DOM（WASM）
  • WASM バンドル: wasm-pack + wasm-bindgen で生成
  • Pyxel API 互換: init / run / cls / blt / text など主要 API を Rust で実装
  • CLI ツール: pyxel_rust_cli.py（Python 製、Pyxel CLI を拡張）

✨ 特徴

  • Pyxel ライクな API — Python Pyxel の知識がそのまま活かせる
  • デスクトップ: pyxel-core（SDL2）または wgpu バックエンド
  • ブラウザ: wasm-bindgen + Canvas 2D API（Emscripten 不使用）
  • 高パフォーマンス — GPU 描画バックエンド（wgpu、デスクトップのみ）
  • クロスプラットフォーム — デスクトップ / ブラウザ 両対応
  • Python CLI ツール — pyxel_rust_cli.py で Pyxel CLI コマンドを拡張

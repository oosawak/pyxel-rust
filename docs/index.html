🎮 Pyxel-Rust

Rust WebAssembly wasm-bindgen Canvas 2D SDL2

Pyxel にインスパイアされた Rust 製 2D ゲームライブラリ。
wasm-bindgen を使ってブラウザ上でも動作します（Emscripten 不使用）。

GitHub リポジトリを見る (oosawak/pyxel-rust)
⚠️ 開発中 — API・仕様は予告なく変更される可能性があります。

🏗️ バックエンド構成

用途に応じて3つのバックエンドを切り替えられます：

バックエンド 対象 使用ライブラリ feature フラグ
pyxel-core-backend デスクトップ（デフォルト） pyxel-core (SDL2) pyxel-core-backend
wgpu-backend デスクトップ（代替） pixels + winit wgpu-backend
wasm-backend ブラウザ wasm-bindgen + web-sys (Canvas 2D) wasm-backend

※ ブラウザ版は wasm32-unknown-unknown ターゲットで wasm-pack を使ってビルドします。Emscripten は使用していません。

✨ 特徴

  • 🦀 Rust 製コア — 型安全で高速
  • 🌐 WASM 対応 — wasm-bindgen / wasm-pack でブラウザ向けにビルド
  • 🖼️ Canvas 2D 統合 — ブラウザでは web-sys 経由で Canvas 2D API を使用
  • 🎮 Pyxel 互換 API — init / run / cls / blt / text など主要 API を実装
  • 🐍 Python CLI — pyxel_rust_cli.py（Python 製）で Rust ゲームのビルド・実行を管理
